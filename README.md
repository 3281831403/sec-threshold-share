密钥托管改成分片保存之后，任意两片拼起来就能还原主密钥，门限形同虚设：伽罗瓦域乘法直接做普通整数乘法后取低八位而不按不可约多项式约减；乘法逆元用浮点幂近似求倒数导致小值错位；拉格朗日插值分母只把坐标差连乘却不求乘法逆；插值系数按 x 的幂次累加时漏掉模 256 约减；Horner 求值从高次开始却按低次顺序传入系数使多项式次序颠倒；分片坐标允许为零导致零坐标分片让插值退化；重复坐标不去重使同一分片提交两次即可降门限；校验字节只覆盖坐标不覆盖载荷使载荷篡改无法发现；门限为一时仍走插值路径使单分片还原出错；分片顺序影响还原结果因为插值前未按坐标排序。share/split.py 是核心，tests/test_split.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。

pyproject 布局说明
pyproject.toml 的 pytest 配置把 pythonpath 设置为 src，因此测试可以直接导入 share.split，不需要安装包。src/share/split.py 是唯一实现文件，恰好 8 个函数：gf_mul、gf_inv、_gf_pow、eval_poly、split、combine、verify_share、reconstruct。src/share/__init__.py 只负责导出这些函数。

分片格式
每片是一个 bytes：第 1 字节为坐标，中间为与原文等长的载荷，最后 1 字节为校验字节。坐标在 GF(256) 中必须非零且在 1 到 255 之间。reconstruct 返回字典，键 secret 为还原出的 bytes，键 used 为实际参与还原的分片集合。

实现约束
只修改 src/share/split.py。保持 8 个函数的名称与签名不变。禁止引入第三方依赖。实现必须真正使用 GF(256) 的不可约多项式 x^8 + x^4 + x^3 + x + 1 做乘法约减、乘法逆元、Horner 求值和拉格朗日插值，并用精确字节比较通过全部测试。
